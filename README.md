# Monkey

Implementation of the **Monkey programming language** from [Writing an Interpreter in Go](https://interpreterbook.com/) by Thorsten Ball.

## Goal

Learn how interpreters work by building one from scratch in Go.

## Progress

- [ ] Lexer
- [ ] Parser
- [ ] AST
- [ ] Evaluator
- [ ] Functions & Closures
- [ ] Arrays & Hashes
- [ ] Macros
- [ ] REPL

## Running

```bash
go run .
```
